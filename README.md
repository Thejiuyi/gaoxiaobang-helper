# 高校邦助手 · 全能合并版

一个用于**高校邦**在线课程平台的 Tampermonkey 用户脚本：静音自动播放、按目录进度自动跳章、整卷测验 AI 作答、讨论区 AI 回复。

当前版本 **v1.0.1**。

---

## ⚠️ 使用前请先读这一段

**这是一个「自动化刷课」脚本。** 它会替你播放视频、跳章节、回答测验并**真的交卷**。
在用它之前，请确认你清楚下面几件事：

1. **「测验自动作答」是唯一不可撤销的功能**，**默认关闭**。
   打开后它会真的替你交卷 —— 每套测验通常只有 1~3 次机会，**交一次少一次**，
   而 AI 的答案**不保证正确**。对只剩 1 次机会的测验，答错就是该章 0 分，无法补救。
   **脚本不会拿残缺答案凑合交卷**：AI 答不出来时它会停下来并把原因写在页面上，而不是赌一把。
2. **请先在一门不重要的课上试**，确认行为符合预期再用于正式课程。
3. **本脚本不保证符合你所在平台的使用条款。** 使用风险由使用者自行承担。
   作者不对任何成绩、学籍或账号后果负责。
4. 脚本**不干预播放速度**（平台有检测）。需要倍速请用 Global Speed 之类的扩展自行控制。

## 功能

| 功能 | 说明 |
|---|---|
| **静音自动播放** | 自动播放视频/音频，并对抗平台的「切走标签页就暂停」 |
| **按目录进度自动跳章** | 视频 / 音频 / 文档 / 讨论 / 测验统一按目录里的完成状态判定，而不是猜时长 |
| **测验 / 作业章节可独立配置** | 「跳过」或「先答完再跳」，默认跳过 |
| **逐题自动答题** | 视频里的弹题 |
| **整卷测验 AI 作答** | ★不可撤销，默认关。含「已提交就绝不再答」的守卫 |
| **讨论区 AI 回复** | 三种模式：跳过 / 抄答案 / 接入 API 生成 |
| **顶部控制面板** | 贴顶、可拖动、可最小化；**所有配置都在这里**，改完立即生效 |
| **AI 失败可诊断** | 返回空内容时给出**具体原因**（而不是一句「失败了」），并按额度阶梯自动重试 |

## 安装

1. 浏览器先装 **Tampermonkey**（篡改猴）扩展。
2. **点这一行直接安装**（Tampermonkey 会自动弹出安装页）：

   ### 👉 [安装 高校邦助手 v1.0.1](https://raw.githubusercontent.com/Thejiuyi/gaoxiaobang-helper/main/userscript/5-高校邦助手-全能合并版-v1.0.1.user.js)

   没弹窗 = 第 1 步的 Tampermonkey 没装好。
   手动方式：打开 [`userscript/`](userscript) 目录 → 点开 `.user.js` 文件 → 点右上角 **Raw**。
3. 打开高校邦课程页面，网页**顶部中间**会出现一条蓝色面板。

> ⚠️ **只装一份。** 如果你之前装过旧版（尤其是 `@namespace` 不是
> `https://github.com/Thejiuyi` 的那份），**先到篡改猴管理面板删掉旧版**。
> 两版共存会互相抢跳章，表现为「新版好像没生效」。
> 脚本自带的多实例自检会在页面上弹红条提醒你这种情况。

## 配置

**所有配置都在页面顶部的面板里**，点标题栏的「设置」：

```
AI 接口     服务商预设 / API 地址 / API Key / 模型名 / [测试 AI 连接]
功能开关    自动播放视频 · 自动跳下一章 · 非视频章节跳过 · 失焦防暂停 · 自动答题 · 调试日志
测验 / 作业  章节处理方式 · ★测验自动作答
讨论区      讨论题处理方式（跳过 / 抄答案 / 接入 API）
界面        显示暂停按钮 · 显示控制面板 · 重置面板位置
```

**改完立即生效，不用刷新页面。**

### 需要自己准备 AI 接口

讨论区回复和整卷测验需要一个大模型接口（OpenAI 兼容格式）。点「服务商预设」可以一键填好地址和模型名，
你只需要再填 **API Key**。

- **API Key 保存在浏览器本地**（Tampermonkey 的 `GM_setValue`），**不会写进脚本源码，也不会发给作者**。
- 填完点「**测试 AI 连接**」验证 —— 它会**分两步**测：
  1. 一个短问题（验证地址 / Key / 模型名通不通）
  2. **按整卷测验的真实形状**再测一次（长题目 + 强制 JSON）

  ⚠️ 只看第 1 步会给你**误导性的通过**：短问题能过，不代表整卷能过。
  推理模型在长问题上「思考」会变多，可能把输出额度吃光，表现为「返回内容为空」。
  这种情况下第 2 步会明确告诉你是额度问题，并建议换成非推理模型（`deepseek-chat` / `qwen-plus` / `glm-4-flash` 这类）。

## 它不会做什么

- **不会在课程目录页自动跳章**（`/class/<id>/unit`）—— 那是你挑章节的地方。
- **不会碰这些页面**：公告、成绩分析、测验/作业/考试列表、讨论区列表、错题本、活动页。
  这些页面上按钮会显示「本页不适用」。
- **不会干预播放速度**。
- **不会用残缺的 AI 答案凑合交卷**。
- **不会上传你的任何数据**（除了你自己配置的 AI 接口请求）。
